## 三、结论先行：做什么、不做什么

### 不做（已判定，不再讨论）

| 不做                                       | 理由                                                         |
| ------------------------------------------ | ------------------------------------------------------------ |
| 品牌保护 SaaS（Red Points 中国版）         | 替代型天花板 + 在位者已在北京设点 + 平台免费通道截流         |
| 以"自动化投诉"为核心价值的任何产品         | 阿里 IPP、京东、抖音、Amazon Brand Registry 已把这一层做成免费功能 |
| 上架前侵权排查工具                         | 该层已价格战至免费试用，AI 使其持续通缩                      |
| 钓鱼取证 + 批量施压 + 快速和解的原告侧套利 | **道德红线**。见第八节 R1                                    |
| 写 BP、招人、开发软件                      | 需求侧证据为零，任何建设性投入都缺乏依据                     |

### 做

**产品形态定性：不是软件产品，是律所的获客入口。**

用 AI 低成本产出一份可核验的免费诊断报告作为钩子，收费点全部发生在报告之后、由律师团队交付。

**免费报告（钩子）四项内容**

| #    | 内容                                                     | 数据可得性           |
| ---- | -------------------------------------------------------- | -------------------- |
| 1    | 你的商标／专利在中国是否已注册、是否被抢注               | 可查，公开库         |
| 2    | 中国主流平台疑似仿品链路数量与集中度                     | 可抓，需工程量       |
| 3    | 同类案由近三年判赔中位数、审理周期中位数、外国原告胜诉率 | **`Ø`，见第七节 C1** |
| 4    | 一句话结论：值得打／先补权利／不值得打                   | 由律师定论，非 AI    |

**收费点（全部在报告之后）** 权利补注册（低客单高频，受 Q2 约束）→ 案件代理（高客单）→ 年度监测订阅

**唯一可能的飞轮**：侵权源头图谱（谁在仿、从哪出货、关联账号），使第 N 个客户成本低于第 1 个。 但飞轮的输入端（地面调查）是全链条最贵的一段，起动条件未评估，记为 `H`。软件本身没有飞轮。

## 五、Gate 1｜入口测试（**本方案的核心争议点**）

### 已知事实

我方在境外信息场中**不存在**（Gate 0 附加问题若答案为 0，这就是已知事实，不是待验假设）。

### 两条候选路径

|                | 路径 A｜境外直客冷启动                                       | 路径 B｜中间层转介                                           |
| -------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 对象           | 单一垂直（如汽配／五金）的境外中小品牌                       | 境外知产律所的中国业务转介；境外品牌保护 SaaS 的中国落地转包；行业协会与商会 |
| 对象数量       | 以万计，**不可枚举**                                         | 以十计，**可穷举**                                           |
| 天花板         | 高。客户关系归我方，飞轮数据归我方                           | **低。可能沦为供应商，价格被压，客户关系与数据不归我方**     |
| 摩擦           | 可信度从零建、语言、时差、中国域名冷邮件送达率               | 说同一种专业语言，转介是对方的常规动作                       |
| 冷启动期望回信 | 20 封 → **0.2～1 封**（按 1–5% 行业常态）                    | 20 个对象 → 可获得明确"要／不要"                             |
| **可归因性**   | **极差**。0 回信无法区分：样本太小／名单错／可信度／语言格式／报价单本身 | **好**。对象少，可以追问"为什么不"                           |

### 本方案的选择：**先 B 后 A，不是二选一**

理由：Gate 1 的目的不是找到最大的市场，是**用最低成本获得一个可归因的答案**。路径 A 在 n=20 时最可能的结果是 0，而这个 0 无法解释——它既可能意味着市场不存在，也可能只意味着这封邮件写得不好。**一个不可证伪的实验不该作为第一道闸门。**

路径 A 的天花板确实更高，因此它不被删除，而是**移到 Gate 2**，并用 Gate 1 获得的真实定价与交付事实重新设计。

### Gate 1 执行

1. 完成 Gate 0（前置，不可跳过）
2. 穷举中间层对象名单，目标 15–25 个可联系主体
3. 准备一页纸能力说明（不是免费报告，中间层不需要钩子，需要的是资质与案例）
4. 逐一接触，目标是**取得明确答复并追问原因**

### Gate 1 判据（先定死）

| 结果                                          | 判定                                                   |
| --------------------------------------------- | ------------------------------------------------------ |
| ≥3 个对象表达明确的合作意向或提出具体案件场景 | **通过**，进入 Gate 2                                  |
| 1–2 个                                        | **挂起**，补充名单一轮后复评，不得无限延长             |
| 0 个明确意向，**且能收集到具体拒绝理由**      | 记录拒绝理由，据此判断是能力问题、资质问题还是需求问题 |
| 0 个回应且**无法取得任何拒绝理由**            | 判定为我方接触方式失败，**不得判定为市场不成立**       |

**归因范围声明（必须随判据一同记录）**

> 本轮结论仅适用于**本名单、本接触方式、本时点**，不得外推为"境外权利人中国维权服务不成立"或"获客路径整体不成立"。

**Gate 1 成本估算**（`H`，未验证）

- 现金：≈ 0
- 人工：杨 + 律师团队 1 人，各约 10–15 小时
- 周期：2–3 周
